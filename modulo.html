Explicación Funcional del Módulo

help_center

¿Qué problema soluciona?

Muchos estudiantes abandonan los cursos de idiomas porque se inscriben en niveles equivocados (muy fáciles o muy difíciles). Este módulo elimina la fricción inicial, diagnosticando el nivel del usuario de forma autónoma antes de la compra.

person_play

¿Cómo interactúa el usuario?

El usuario se enfrenta a un entorno gamificado. Selecciona la respuesta que considera correcta mediante botones interactivos (Radio Buttons personalizados) y avanza por 5 preguntas. El DOM se actualiza dinámicamente sin recargar la página, ofreciendo una experiencia fluida.

settings_suggest

¿Cómo funcionaría para el cliente real?

Al finalizar el test, el sistema calcula el puntaje total usando condicionales lógicos en JavaScript. Dependiendo del resultado (ej. 0-2 puntos = A1, 3-4 = A2, 5 = B1), el módulo le sugiere un plan específico de nuestra página de "Cursos", actuando como un embudo de ventas automatizado.
